# 第 7 章 网络基础

本章是“网络基础”模块的导入。模块分为两部分：先补充理解后续内容所需的通用网络知识，再进入与 WebRTC 直接相关的连接问题。

## 通用网络知识

第一部分包含三节课，分别介绍 UDP 与 TCP 的工作方式，以及 HTTP 和 WebSocket。它们并非 WebRTC 专属技术，但在后续讨论信令时都会用到。

## WebRTC 连接与 NAT 穿透

第二部分更聚焦于 WebRTC，首先讨论 NAT 穿透。它使一个浏览器能够直接与另一个浏览器通信，而不必让媒体沿途经过 Web 服务器，是理解 WebRTC 工作方式的关键，尤其值得没有 VoIP 背景的读者反复学习。

本模块随后还会介绍 VoIP 的三个层级，以及课程讲师对创新发生位置和技术随时间演进的看法。
