# 第 24 章 编解码器概述

模块四开始讨论编解码器。这是 WebRTC 和整个 VoIP 技术的重要组成部分，也为后续理解媒体处理奠定基础。

## 模块结构

本模块分为语音编解码器和视频编解码器两部分。两部分都先介绍基本概念与工作原理，再进入具体编解码器：

- **语音部分**：以 Opus 为主，课程建议 WebRTC 使用该编解码器，随后再讨论其他语音编解码器及其在 WebRTC 中的位置。
- **视频部分**：先介绍课程所列的 WebRTC 必需编解码器 VP8 和 H.264，再讨论 VP9，以及开放媒体联盟（Alliance for Open Media）所代表的后续发展方向。

这样的安排先建立语音与视频编码的共同基础，再比较具体实现，避免把编解码器名称当作无需理解的选项清单。
