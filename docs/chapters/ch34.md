# 第 34 章 媒体处理概述

理解编解码器之后，下一步是研究媒体如何通过网络发送，以及系统在传输过程中如何以不同方式处理这些信息。本模块围绕这条链路展开。

## 本模块的主要内容

- **RTP、RTCP 与 SRTP**：先理解 RTP 和 RTCP，再说明 SRTP 的工作原理。SRTP 是 WebRTC 以及许多其他网络协议使用的媒体传输方式。
- **多方群组通话**：比较网状（mesh）、混合（mixing）和路由（routing）三种架构。
- **录制**：介绍客户端录制与服务器端录制等选择，以及不同方案的优缺点。
- **转码**：简要说明转码及其不同技术。

这些内容共同回答一个问题：音视频完成编码后，如何安全、有效地传输，并适应多方通信、录制和格式转换等处理需求。
