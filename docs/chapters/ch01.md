# 第 1 章 课程介绍

本章说明 WebRTCcourse.com 上开发者学习路径的构成，并梳理 Advanced WebRTC Architecture 课程的知识地图、配套课程与学习工具。免费的 WebRTC Basics 就是架构课程的第一个模块，因此这份介绍同时适用于两者。

## 讲师与课程定位

课程讲师是 BlogGeek.Me 的维护者，也是数字通信领域的顾问和分析师，主要研究 WebRTC、通信平台即服务（CPaaS），以及与这些领域交叉的机器学习和人工智能。他曾联合创办 TestRTC；这项服务专注于 WebRTC 应用的测试与监控，讲师也在其后续收购方继续从事相关产品管理工作。

WebRTCcourse.com 将课程分为两条路径：

- **支持路径**：面向需要协助用户排查 WebRTC 问题的支持团队。
- **开发者路径**：面向需要构建产品并作出技术决策的人，包括开发者、产品经理、系统架构师和质量保证团队。

本课程属于开发者路径。它的目标不仅是解释概念，还要帮助学习者理解 WebRTC，能够把实际问题转化为合适的架构，再进一步实现解决方案。

## 高级 WebRTC 架构课程的知识地图

按课程录制时的安排，架构课程共有 8 个模块、56 节课、4 次测验，录播视频约 19 小时；这些数量描述的是当时提供的课程内容。第一模块单独构成免费的 WebRTC Basics，其余模块在此基础上逐层深入。

| 模块 | 主题 | 主要内容 |
| --- | --- | --- |
| 1 | WebRTC 基础 | WebRTC 的定义、历史与用途，浏览器和设备覆盖，浏览器中的主要 API，以及课外学习资源。 |
| 2 | 网络基础 | TCP 与 UDP 的可靠性和顺序性；浏览器中的 HTTP、WebSocket 与 WebTransport；NAT 穿越以及 ICE、STUN 的使用和最佳实践；VoIP 的三层结构；抖动、时延、比特率、丢包等媒体质量指标。 |
| 3 | WebRTC 信令 | 传输与信令协议的选择，会话描述协议（SDP）的结构和解析，WebRTC 已有安全机制与开发者仍需补充的安全工作，以及屏幕共享。 |
| 4 | 编解码器 | 语音和视频编解码的基本概念与有损特性；音频方面的 Opus；视频方面的 VP8、H.264、VP9、HEVC 和 AV1，并据此理解如何为应用选择编解码器。 |
| 5 | 媒体处理 | RTP 与 RTCP、带宽估算及其对视频处理的影响；网状（Mesh）、混合（Mixing）和路由（Routing）架构的适用场景；录制方案与媒体领域的人工智能。 |
| 6 | 第三方框架和服务 | 自研与购买的开发策略、对解决方案的控制程度，基础设施、信令、媒体服务器、CPaaS 托管方案、VoIP 框架，以及测试和监控服务。 |
| 7 | WebRTC 设计模式 | 媒体流与连接类型，以及会议、带录制的多方会议、网络研讨会、直播、PSTN 接入和大型群组通话优化。重点是把前六个模块的构件组合成实际方案。 |
| 8 | 补充材料 | 标准化与需求文档写作、WebRTC 中的机器学习基础、媒体算法、防火墙配置，视频质量客座课程、在 AWS 上部署 TURN，以及办公时间、AMA 录像和免费迷你课程等额外内容。 |

媒体处理部分特别强调：群组通话常采用路由架构，但网状和混合架构仍有自己的位置。实际解决方案可能组合多种架构，因此需要理解各自的前提，而不是只记住一种“通用答案”。

## 配套课程

开发者路径还提供几类可独立学习的课程：

- **WebRTC: The Missing Codelab**：由讲师与 Philipp Hancke 共同制作，围绕一个简单 WebRTC 通话应用逐段讲解代码、API 的使用动机和实现思路，并配有练习与资源库。它不是只展示 API 调用，而是解释为什么这样构建应用。
- **Low Level WebRTC Protocols**：从 UDP、TCP，到 STUN、TURN、ICE，再到 SRTP、RTP、RTCP、DTLS 和 SCTP，逐项分析协议，并介绍如何使用 Wireshark 阅读这些协议。
- **Higher Level WebRTC Protocols**：重点研究 RTP、RTCP 及其扩展机制，包括包化、抗损、解复用、RTP 头部扩展、发送者报告和接收者报告，并进一步讨论带宽估算等改善媒体质量的算法。
- **WebRTC Tooling**：一类内容通过访谈工具背后的开发者，介绍开源与商业解决方案及框架；另一类以代码片段补充主课程未覆盖的主题。

这些课程与架构课程的侧重点不同：架构课程解决“如何组合并设计系统”，Codelab 偏重动手实现，协议课程深入内部机制，工具课程帮助了解生态。

## 学习体验与工具

课程通过学习管理系统（LMS）组织内容。每节课通常包含分章节的视频、相关资源和链接；材料区还可能提供速查表、视觉资料、课程简报、问答、相关术语表，以及 Kranky Geek、WebRTC Fiddle of the Month 和 AMA 等内容的链接。资源链接通常比视频更新得更频繁，适合在复习时再次查看。

学习过程中可以使用以下功能：

- 在课程清单 PDF 或 LMS 中标记完成进度，也可收藏课程并做笔记。
- 通过主要模块末尾的 4 次测验检查理解程度。
- 参加每月一次、分两个时区举行的 AMA。活动先围绕一个 WebRTC 主题展开，再开放提问；录像会放入补充材料模块。
- 使用网站在线聊天或 Slack 工作区交流。课程提到的主要 Slack 频道包括 WebRTC 开发和 WebRTC Codelab。

至此，课程的位置和学习方式已经明确。后续章节将从 WebRTC 的定义与边界开始，建立后续网络、信令、媒体和架构设计所需的共同语言。
