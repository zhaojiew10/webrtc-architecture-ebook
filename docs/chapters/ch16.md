# 第 16 章 WebRTC 信令

第三模块围绕 WebRTC 信令展开，内容大致分为两部分：先讨论信令本身及其传输，再解释 SDP、安全和屏幕共享等相关主题。

## 信令及其传输

第一部分将区分**信令**与**信令传输**：前者关注如何表达和交换会话信息，后者关注这些信息通过什么机制传送。理解二者的区别，是选择适合自身产品的信令协议与传输方案的前提。

## SDP、安全与屏幕共享

随后，本模块将讨论以下主题：

- **会话描述协议（SDP）**：SDP 是课程录制时 WebRTC 使用的重要机制。未来实现方式可能变化，但理解其当前工作方式仍是掌握 WebRTC 架构的必要基础。
- **安全**：既要了解 WebRTC 自身如何处理安全，也要明确开发者仍需在其上完成的工作，以及实现时不能遗漏的注意事项。
- **屏幕共享**：介绍屏幕共享在 WebRTC 中的使用方式。
