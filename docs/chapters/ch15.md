# 第 15 章 模块二小结

模块二介绍了理解 WebRTC 所需的网络基础，重点包括传输协议、浏览器通信方式、NAT 穿越以及 VoIP 的演进。

## 本模块的主要内容

- **TCP 与 UDP**：TCP 面向连接且可靠，UDP 无连接且不可靠，两者在 WebRTC 中都有用途。TCP 较多用于信令，UDP 则主要用于媒体传输。
- **HTTP 与 WebSocket**：二者是浏览器整体通信方案的一部分，后续讨论信令时还需要再次审视它们的作用。
- **NAT 穿越**：即使浏览器之间存在防火墙，也要设法把媒体从浏览器 A 传到浏览器 B。STUN、TURN 和 ICE 共同构成这一问题的核心解决思路。这部分是理解 WebRTC 媒体路径的关键，值得反复复习。
- **VoIP 的层次与创新**：课程还讨论了 VoIP 的技术分层，以及当前创新主要发生在哪些层面。

至此，与 WebRTC 相关的通用网络基础告一段落。下一模块将专门讨论信令，以及产品可以选择的不同信令协议。
