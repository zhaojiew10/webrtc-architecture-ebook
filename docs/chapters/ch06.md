# 第 6 章 模块一小结

第一模块建立了 WebRTC 的整体认识。最重要的结论是：**WebRTC 是一个基础构件，是可以纳入技术栈、用来构建产品或解决方案的一项技术，而不是完整应用。**因此，不应直接把 WebRTC 与 Skype 这样的产品相比较；更有意义的问题是，能否使用 WebRTC 构建出类似 Skype 的解决方案。

本模块还梳理了浏览器和设备覆盖，说明 WebRTC 可以在哪些环境中使用；介绍了 `getUserMedia`、`RTCPeerConnection` 和数据通道三组主要 API，并简要提及 ORTC；最后列出了继续使用和深入学习 WebRTC 所需的课程、网站与社区资源。

这些内容仍然属于基础和高层概览。后续模块将采用**自顶向下**的方式，在已经形成整体图景的基础上逐个深入 WebRTC 的组成要素：下一模块先学习网络，随后进入信令、媒体和编解码器，最后再回到高层视角，把各部分知识组合起来，思考能够用它们构建怎样的解决方案。
