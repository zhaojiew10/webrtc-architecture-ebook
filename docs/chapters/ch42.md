# 第 42 章 模块五小结

模块五围绕 WebRTC 媒体处理展开，并把此前学习的信令知识与实时媒体传输、架构选择联系起来。

## 本模块的核心内容

本模块首先讨论编解码器和媒体处理，随后介绍 RTP 与 RTCP，以及它们在 SRTP 中的工作方式。在多方媒体架构上，课程说明了网状模型难以扩展、集中混音成本较高的问题，再引出媒体路由与选择性转发单元（SFU）模型。

为了适应不同接收端和网络条件，课程还讨论了 Simulcast 与可伸缩视频编码（SVC），并介绍了录制和转码等相关处理能力。加上本模块最后讨论的媒体人工智能，可以看到，WebRTC 媒体系统不仅是把编码数据从一端传到另一端，还涉及转发、适配、存储和后处理等完整链路。

## 从媒体机制转向开发生态

至此，课程已经分别讨论信令与媒体。其中许多机制不仅适用于 WebRTC，也广泛存在于其他 IP 语音和实时通信系统。

接下来的模块将转向 WebRTC 生态系统：开发者如何组织系统架构，如何利用第三方框架、托管服务和其他工具完成开发，以及如何借助这些工具更快、更高效地构建应用。
