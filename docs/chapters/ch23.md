# 第 23 章 模块三小结

模块三围绕 WebRTC 信令展开，介绍了信令传输与协议如何配合应用工作，包括 Comet、XHR 长轮询和 WebSocket 等传输机制，不同信令协议与专有实现，以及 SDP、安全和屏幕共享。

## 从应用流程转向媒体处理

本模块及此前内容主要位于应用层，关注用户如何经历应用流程，以及为了让这些流程正常运行，开发者需要完成哪些工作。

后续模块四和模块五将转向媒体部分，说明媒体及相关技术如何融入完整的 WebRTC 系统。即使最终只负责信令开发，也有必要理解媒体和编解码器：这些知识能够帮助开发者判断 WebRTC 能做什么、不能做什么，并在设计信令与会话流程时理解底层媒体能力的约束。
